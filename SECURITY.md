# Politique de sécurité

## Versions supportées

Seule la **dernière version publiée** reçoit des correctifs de sécurité. Mets ton instance à jour via le bandeau de l'interface ou avec `docker compose pull && docker compose up -d`.

## Signaler une faille

Merci de **ne pas ouvrir d'issue publique**. Utilise le formulaire privé de GitHub :
[Signaler une vulnérabilité](https://github.com/JUC0AG0G0/Back-in-stock/security/advisories/new).

Indique la version concernée, les étapes pour reproduire et l'impact. Tu recevras une réponse dès que possible.

## Plugins tiers

Un plugin est du code exécuté avec les droits de l'application. N'installe que des plugins de confiance. Les failles d'un plugin tiers doivent être signalées à son auteur.
