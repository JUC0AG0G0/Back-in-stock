# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : sois respectueux, bienveillant et constructif. Le harcèlement, les insultes et les comportements discriminatoires ne sont pas tolérés.

Pour signaler un comportement inacceptable, contacte les mainteneurs via les [GitHub Security Advisories](https://github.com/JUC0AG0G0/Back-in-stock/security/advisories/new) ou en privé. Les signalements sont traités de façon confidentielle.
