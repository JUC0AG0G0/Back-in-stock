# Back in stock !

**Back in stock !** tells you as soon as a product is back in stock, or when a new item shows up on a listing page (for example the Fanatec Europe refurbished page).

- **Self-hosted**: one Docker container and one SQLite file. No central server, no account, no telemetry.
- **Two kinds of watch**: a product page (restock, out of stock, preorder) or a listing page (new items).
- **Notifications**: Telegram and email to start with, with several accounts per channel if you want.
- **Plugins**: every site and every notification channel is an isolated module. You can add one without touching the core.
- **English and French**, in the interface and in notifications.

:::caution Work in progress
The technical foundation (M0) is being built. Pages marked "coming soon" describe what lands in the next versions.
:::
