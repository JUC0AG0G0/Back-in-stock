# Back in stock !

Application **open source et auto-hébergée** qui surveille des pages de boutiques en ligne et te prévient quand :

- un produit **revient en stock** ;
- un **nouvel article apparaît** sur une page liste (par exemple la page reconditionné d'une boutique).

TypeScript, Docker, interface web en français et en anglais, sites et canaux de notification ajoutables sous forme de plugins.

> 🚧 Projet en cours de conception. Voir la [spécification](./SPEC.md).

## Contribuer

Les contributions sont les bienvenues, en particulier pour ajouter de nouveaux sites ou de nouveaux moyens de notification. Voir [CONTRIBUTING.md](./CONTRIBUTING.md).
